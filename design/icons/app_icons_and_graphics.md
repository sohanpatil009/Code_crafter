## 📐 Icon Specifications

### Size Guidelines
```
Extra Small:      16dp x 16dp (List icons)
Small:           24dp x 24dp (Standard icons)
Medium:          32dp x 32dp (Important actions)
Large:           48dp x 48dp (Primary buttons)
Extra Large:     64dp x 64dp (Hero actions)
```

### Export Formats
- **Vector**: SVG for scalability
- **Raster**: PNG with transparency
- **Densities**: mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi

### Color Variations
```
Default:         Original colors
Dark Theme:      Inverted/adjusted colors
High Contrast:   Enhanced contrast ratios
Monochrome:      Single color versions
```

## 🎯 Icon Usage Guidelines

### Do's
- ✅ Use consistent icon style throughout app
- ✅ Maintain proper spacing around icons
- ✅ Use appropriate sizes for context
- ✅ Provide alternative text for accessibility
- ✅ Test icons at different sizes

### Don'ts
- ❌ Mix different icon styles
- ❌ Use icons smaller than 16dp
- ❌ Stretch or distort icon proportions
- ❌ Use low contrast color combinations
- ❌ Overcrowd interface with too many icons

## 📱 Platform-Specific Considerations

### Android Material Design
- **Icon Grid**: 24dp grid system
- **Keyline Shapes**: Circle, square, rectangle
- **Finish**: 2dp corner radius for squares
- **Shadows**: Subtle drop shadows for depth

### Accessibility Requirements
- **Contrast Ratio**: Minimum 3:1 for icons
- **Touch Targets**: Minimum 48dp x 48dp
- **Alternative Text**: Descriptive labels
- **Color Independence**: Don't rely only on color
