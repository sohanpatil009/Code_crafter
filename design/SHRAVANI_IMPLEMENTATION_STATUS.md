## 🎯 Key Design Decisions

### 1. Agriculture-Themed Colors
**Decision**: Use green as primary color
**Rationale**: Represents growth, nature, and agriculture
**Impact**: Creates emotional connection with farmers

### 2. Audio-First Approach
**Decision**: Prominent audio controls on results screen
**Rationale**: Many farmers prefer listening to reading
**Impact**: Increases accessibility and user engagement

### 3. Multi-Language Support
**Decision**: 8 Indian languages with native scripts
**Rationale**: Serves diverse farming communities
**Impact**: Removes language barriers for adoption

### 4. Simple, Clean Interface
**Decision**: Minimal UI with clear visual hierarchy
**Rationale**: Reduces cognitive load for users
**Impact**: Improves usability for all skill levels

### 5. Large Touch Targets
**Decision**: 48dp+ touch targets throughout
**Rationale**: Accommodates users with motor difficulties
**Impact**: Improves accessibility and reduces errors
