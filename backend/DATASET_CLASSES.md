### Display name formatting
```python
def format_class_name(class_name):
    """Convert class name to display format"""
    # Example: 'Tomato___Early_blight' -> 'Tomato Early Blight'
    parts = class_name.replace('___', ' - ').replace('_', ' ')
    return parts.title()
```

## Notes

- Class names use triple underscore (___) to separate crop from disease
- Some class names have special characters (parentheses, commas)
- Healthy classes are present for each major crop
- Tomato has the most classes (10) due to its susceptibility to various diseases
- Dataset is balanced across classes for better training
